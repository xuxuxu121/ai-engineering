# Week 2：Python 数据结构与综合实践

## 一、本周学习目标

学习 Python 中常用的数据结构，掌握数据的存储、查询、修改、删除和遍历，并使用这些知识完成一个学生成绩管理系统。

## 二、学习内容

### Day 1：列表（List）
- 创建和访问列表元素
- 使用 `append()` 添加元素
- 使用 `remove()` 删除元素
- 遍历列表
- 使用 `sum()`、`len()`、`max()`、`min()` 进行统计

### Day 2：元组（Tuple）
- 创建元组和访问元素
- 理解元组不可变的特点
- 元组解包
- 使用元组保存固定数据

### Day 3：字典（Dictionary）
- 使用键值对保存数据
- 添加、查询、修改和删除数据
- 使用 `keys()`、`values()` 和 `items()` 遍历字典

### Day 4：集合（Set）
- 理解集合元素的唯一性
- 使用 `add()` 和 `remove()`
- 使用集合进行去重、并集和交集运算

### Day 5：数据结构综合练习
- 根据需求选择合适的数据结构
- 使用列表保存多个学生
- 使用字典保存学生姓名和成绩
- 完成成绩统计与学生信息查询

### Day 6—7：学生成绩管理系统
完成一个基于命令行的学生成绩管理系统。

## 三、项目功能

1. 显示所有学生
2. 添加学生
3. 查询学生
4. 修改学生成绩
5. 删除学生
6. 计算平均成绩
7. 查看最高成绩
8. 查看最低成绩
9. 通过菜单选择功能
10. 通过输入 `0` 退出系统

## 四、使用的 Python 知识

- 列表与字典
- 条件判断与循环
- 函数定义和调用
- `input()` 与 `print()`
- `return` 与 `break`
- `len()`、`max()`、`min()`
- f-string 格式化输出
- 基本的空列表判断

## 五、本周收获

通过本周学习，我掌握了 Python 常用数据结构的基本用法，并学会将列表、字典、循环、条件判断和函数组合起来，完成一个具有多个功能的命令行程序。
